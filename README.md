# mtga_tracker
Tracks win loss history through Magic: The Gathering Arena, gives overall and past 20 game winrate, format winrate and deck winrate.

To use, first go to settings in your MTGA UI, click account, and then check the box titled "Detailed Logs"
Open the py file in your coding environment, you'll need to pip install matplotlib and pandas
run tracker, it may take a few games to correctly start charting, a png will be created to visualize that gets updated after each match.
